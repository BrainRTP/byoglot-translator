The original SVG files and upstream LICENSE.txt are included in this directory. SVG files were converted to PDF for the macOS asset catalog; geometry is unchanged and color is applied at render time. No Font Awesome fonts or code are included.

To regenerate each PDF, run rsvg-convert --format pdf --dpi-x 72 --dpi-y 72 --width 20 --height 20 --keep-aspect-ratio --output <asset.pdf> <source.svg>.
For settings tab icons (sliders, server, regular-pen-to-square, circle-info), use --width 16 --height 16 --page-width 20 --page-height 20 --left 2 --top 2 to preserve space around the original geometry.
