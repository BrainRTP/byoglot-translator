# Задание: проверка ошибок смысла

Другой судья пометил несколько машинных переводов как ошибку смысла. Проверь каждый пункт независимо. Работай только с файлом, который тебе дали, не ищи существующие переводы.

Свобода перевода разрешена и ошибкой не считается: деление длинных фраз, перестановка, выброшенные пустые слова вроде "actually", замена оборота на естественный, принятый жаргон вместо буквального термина. Корявый стиль тоже не ошибка смысла.

Ошибка смысла подтверждается, если читатель перевода поймет другое, чем читатель оригинала: потерян или искажен факт, условие, отрицание, число, ссылка или связь между частями; пропал кусок содержания; добавлено утверждение, которого нет в оригинале; термин переведен так, что обозначает другое понятие.

Запиши JSON-файл по указанному пути. Ключ это id из заголовка пункта (`b34:A`), значение содержит решение и короткое объяснение:

```json
{
  "b34:A": { "confirmed": true, "why": "потеряно условие" },
  "b40:C": { "confirmed": false, "why": "допустимая перестройка" }
}
```
