# Font Awesome Configuration

## Integration

- **Method:** Локальные векторные ресурсы SwiftUI для Mac приложения в apple/Mac, исходные SVG конвертируются в PDF для Assets.xcassets.
- **Version:** 7.3.1
- **License:** Free, CC BY 4.0 для иконок.
- **Families:** classic

## Defaults

- **Style:** solid
- **Family:** classic

## Import Pattern

`ByoIconButton(title: "main.copy", image: Image("fa-copy"), action: copy)`

## Conventions

- Область интеграции: apple/Mac. Браузерная часть монорепозитория и iPhone не используют Font Awesome.
- Иконки: copy и arrow-up-right-from-square. Имена ресурсов: fa-copy и fa-arrow-up-right-from-square.
- Исходные SVG, лицензия и уведомление находятся в apple/Mac/FontAwesome. Сохранять комментарии SVG и атрибуцию, брать файлы из официального релиза.
- Векторные PDF находятся в apple/Mac/Assets.xcassets. Высота до 20 пунктов, режим template; ByoIconButton сохраняет область нажатия 44 на 44, подсказку и доступное имя.
- Способ конвертации указан в apple/Mac/FontAwesome/NOTICE.txt. Атрибуция доступна в разделе «О приложении» на Mac.
